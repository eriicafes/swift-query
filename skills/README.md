# SwiftQuery Skills

Reusable AI agent skills for building with [SwiftQuery](https://github.com/eriicafes/swift-query).

## Install

```sh
npx skills add eriicafes/swift-query
```

## Available Skills

| Skill | Description |
|---|---|
| [`swift-query`](./swift-query/SKILL.md) | Query models and fetchers, cache policies, providers, query clients, live updates with `subscribe`, and mutations for SwiftQuery |
