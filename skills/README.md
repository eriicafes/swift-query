# SwiftQuery Skills

Reusable AI agent skills for building with [SwiftQuery](https://github.com/eriicafes/swift-query).

## Install

```sh
npx skills add eriicafes/swift-query
```

## Available Skills

| Skill | Description |
|---|---|
| [`swift-query`](./swift-query/SKILL.md) | Query models, cache policies, providers, query clients, streams, and optimistic mutations for SwiftQuery |
